A project I am working on to make a small alert device that will go into key fobs. It will support free fall & impact detection to alert the holder of drops.

This project utilizes the following components:
Microcontroller: ATtiny1614
Speaker: Piezo Buzzer
DC-DC Voltage Booster: TLV61046ADBVT
Accelerometer: LIS2DH12
Battery Mgmt System: IP5306
